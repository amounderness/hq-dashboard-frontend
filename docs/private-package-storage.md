# Private package storage

Cloudflare R2 bucket `switchboard-private-packages` was created with Standard storage on 25 September 2026. The dashboard reported **Public Access: Disabled**. It holds a fictional preview release and two immutable Leeds public-results releases. The Worker binding is `SWITCHBOARD_PACKAGES`; no R2 URL or credential is exposed to the browser. The existing Cloudflare Access policy still protects all pages, APIs, assets and preview traffic.

Objects use `releases/<package-id>/...`, with `active.json` at the bucket root. The active pointer contains a package ID and the SHA-256 of that release's `manifest.json`. The server rejects an invalid pointer, a mismatching manifest, a manifest without `publication_allowed: true`, or any factual release object whose SHA-256 does not match the manifest. Upload all immutable release objects first, read them back and check hashes, then write `active.json` last. A rollback changes only the pointer to a previously validated version; do not overwrite release objects in place.

The pointer now selects `leeds-public-results-v0.2.1`, which contains public election results, official ONS ward geometry and aggregate retrospective Forecast tests. All 30 release objects were downloaded again and byte-checked before activation. Previous pointers for `synthetic-owner-preview-v0.1.0` and `leeds-public-results-v0.2.0` are retained in the local audit workspace for rollback. The original development package `leeds-local-elections-v0.1.0` is **not** in R2 and retains `publication_allowed: false`. The published release excludes the unverified census layer and all party-supplied data. See `leeds-release-audit-2026-09-25.md` for source discrepancies and limitations.

Cloudflare's [R2 pricing](https://developers.cloudflare.com/r2/pricing/) lists 10 GB-month Standard storage, one million Class A operations and ten million Class B operations in its monthly free tier; usage above those amounts is billable.
