# Leeds Pulse v0.5.0 · pilot release audit · 26 September 2026

**Live private preview:** `switchboard-owner-preview.keenanrclough.workers.dev` behind the existing owner-only Cloudflare Access policy. **Active package:** `leeds-pulse-v0.5.0`; 33 wards, 167 contests, 945 candidate records across 2021–2026. The package has 35 manifest-hashed data objects plus `manifest.json`; it contains no party-supplied or individual-voter records. The previous `leeds-pulse-v0.4.0` remains an immutable recovery target.

## Source decisions

The [council-hosted Farnley & Wortley declaration](https://datamillnorth.org/download/20jwj/7f3/Farnley%20%26%20Wortley%20ward%20by-election%20-%2010%20October%202024.pdf) for 10 October 2024 is blank. [West Leeds Dispatch](https://westleedsdispatch.com/farnley-wortley-by-election-result-green-partys-david-blackburn-retakes-seat/) supplies a complete seven-candidate result and 20.15% turnout, broadly corroborated by the [secondary election summary](https://en.wikipedia.org/wiki/2024_Leeds_City_Council_election#Changes_between_2024_and_2026). The new package records David Blackburn (Green) with 1,450 votes; Labour 965; Reform UK 912; Conservative 202; Liberal Democrat 118; Independent 70; SDP 26. These sum to 3,743 candidate votes. The contest, ward history, SDP row, source register and report label the **secondary** origin and blank official declaration. Electoral roll size, ballots cast and rejected ballots were not inferred.

The [official Morley South declaration](https://datamillnorth.org/download/20jwj/bbw/Morley%20South%20ward%20by-election%20-%2012%20June%202025.pdf) supports the six candidate votes, Ryan Taylor's 2,119-vote win and 13 rejected ballots already in v0.4.0. The [secondary election summary](https://en.wikipedia.org/wiki/2024_Leeds_City_Council_election#Changes_between_2024_and_2026) supplies 31.7% turnout; its 5,767-ballot count differs by one from 5,755 official candidate votes plus 13 rejected ballots. v0.5.0 displays **31.7% as approximate secondary turnout**, with that discrepancy visible. The official candidate votes are unchanged.

The other 15 candidate-vote disagreements between council archive and Commons Handbook remain labelled, with Handbook figures retained. The archive was checked for the two by-elections above, but an exhaustive council event register has not been certified. “Latest recorded” is still a per-ward poll view, not a councillor register. [The source-decision register](leeds-source-issues-2026-09-26.md) lists each remaining correction request and councillor/party-change context. The current 99-seat composition comes from a [separate council snapshot](https://www.leeds.gov.uk/councillors-and-democracy/councillors-and-committees), retrieved 26 September 2026.

## Build and publication checks

`tools/build_leeds_pulse_v3.py` copies hash-checked v0.4.0 objects, adds the Farnley poll, updates Morley turnout and all affected summaries, and emits a new immutable manifest. `tools/test_leeds_pulse_v3.py` verifies every object hash, candidate and party totals, source notes, ward history, unchanged 2026 latest result, SDP summary and composition. The existing release validator and owner-control tests also passed. The owner validation additionally checked all 35 data objects and election invariants. The production Next build, lint, and Vinext Worker build passed. Final Worker version `3a4d3925-421d-4f9c-8e26-afedf56a80e4` was deployed.

The owner screen recorded approval with a source-review reason and activated v0.5.0. In the signed-in live Explorer, the 2024 Farnley view showed its October by-election and allowed switching to the May scheduled poll; the 2025 Morley view showed the labelled approximate turnout. The Farnley report displayed the secondary link, full tally and caveat. Its downloaded CSV included the package ID, poll date, source URL, candidate votes and quality note. The owner screen then rolled back to v0.4.0, recorded both recovery audit entries, and reactivated approved v0.5.0, which is the final live state. A final rehearsal confirmed that rollback refreshes all page data automatically and the following activation restores v0.5.0 source notes. Signed-out requests for the site, owner API and package API redirected to Cloudflare Access with HTTP 302.

## Pilot limits and next stage

The package is suitable for a **small labelled viewer pilot**, subject to the owner inviting named viewers. A corrected Farnley council declaration, official Morley turnout, council explanations for the 15 candidate differences, and an exhaustive event register remain source follow-ups. Those do not invalidate the disclosed pilot figures, but should be resolved before claiming a fully certified historical series. Viewer-specific role denial, invitation/revocation and usability feedback belong to stage 04. Forecast remains retrospective research and is not a 2027 prediction.
